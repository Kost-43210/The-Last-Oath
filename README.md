# The-Last-Oath-V1.10-for-Windows-x86-32
I created this repository with good intentions only. This is simply a fan-made build for Windows x86-32. I make no claim to the developer's rights, fame, or credit. The official developer is Final Offer and Spocx. For this build to work, you need the game on Steam.
Download the zip archive and place in the steam folder with games, for example, in end it will be: "D:\SteamLibrary\steamapps\common\The Last Oath for Windows x86-32.zip". Unzip the archive and replace the original "The Last Oath" folder, do not change the file name.
Now you can run the game from steam and it will be x86-32!
